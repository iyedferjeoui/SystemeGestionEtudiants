🎓 Système de Gestion des Étudiants

A Student Management System written in C, developed and extended as part of 
my Computer Science studies at ISSAT Sousse.

---

## 📋 Description

This program allows users to input, manage, and display student information 
through a console interface. It goes beyond basic course requirements by 
implementing dynamic memory management, structured data modeling, and 
thorough input validation — applying core C concepts in a practical, 
functional project.

## ✨ Features

- ➕ Add new students (ID, full name, age)
- 📋 Display all registered students
- 💾 Save and retrieve student data
- ✅ Input validation and error handling

## 🛠️ Concepts Used

- `struct` — to model student data cleanly
- Pointers and memory addresses
- Dynamic memory allocation (`malloc`, `free`)
- Loops, conditions, and data validation

## 🚀 How to Compile & Run

Make sure GCC is installed on your system.

**Linux / macOS:**
```bash
gcc etudiant.c -o etudiant
./etudiant
```

**Windows:**
```bash
gcc etudiant.c -o etudiant.exe
etudiant.exe
```
