# 🎓 Système de Gestion des Étudiants

A Student Management System written in **C**, developed as part of my Computer Science coursework at ISSAT Sousse.

## 📋 Description

This program allows users to input, save, and display student information through a simple console interface. It demonstrates core C programming concepts applied in a practical project.

## ✨ Features

- ➕ Add new students (ID, full name, age)
- 📋 Display all registered students
- 💾 Save and retrieve student data
- ✅ Input validation and error handling

## 🛠️ Concepts Used

- `struct` — to model student data
- Pointers and memory addresses
- Dynamic memory allocation (`malloc`, `free`)
- Loops, conditions, and data validation

## 🚀 How to Compile & Run

Make sure you have **GCC** installed.
```bash
gcc etudiant.c -o etudiant
./etudiant
```

On Windows:
```bash
gcc etudiant.c -o etudiant.exe
etudiant.exe
```
